# Отчёт по практической №1

## 1. Вариант и масштаб

| Поле | Значение |
|---|---|
| ФИО | Радуль Неманя |
| Вариант | Q16 |
| Масштаб | sf10 |
| Почему выбран такой масштаб | Я выбрал sf10, потому что этого объёма достаточно, чтобы увидеть разницу между кодеками сжатия GZIP и ZSTD по размеру файлов и по времени записи. Если бы я взял меньший масштаб, например sf1, данных было бы слишком мало, поэтому всё считалось бы за секунды, и разницу между кодеками было бы трудно заметить и понять. Если бы я взял больший масштаб, таблицы создавались бы намного дольше и занимали бы много места на диске, а у меня сейчас и так осталось мало свободного места. Поэтому для меня sf10 является наилучшим выбором. |
